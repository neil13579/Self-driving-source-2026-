## 🐛 Troubleshooting 5 Common Issues

### ❌ "Connection refused"
```bash
# Port 5000 might be in use. Try different port:
# Edit last line of unified_server_simple.py:
app.run(port=5001)
```

### ❌ "unified_visualization.html not found"
```bash
# Make sure all files are in same folder:
ls -la unified_*.html
ls -la unified_*.py
```

### ❌ "ModuleNotFoundError: flask"
```bash
pip install --upgrade flask flask-cors
```

### ❌ Blank 3D viewer
```bash
# Check API is returning data:
# Visit: http://localhost:5000/api/data/lidar
# Should show JSON data
```

### ❌ Low FPS / Slow
```bash
# Reduce point count in unified_server_simple.py:
def generate_lidar_points(self, count=4000):  # ← Reduce from 8000
```
