🚀 Quick Start

  • Start CARLA: CarlaUE4.exe -windowed -carla-port=2000
  • Start Foxglove server: python foxglove_server.py
  • Click one of the options above to connect
  • Server streams on ws://localhost:8766

📡 Available Topics in Foxglove

  • /camera/rgb - RGB camera feed (JPEG compressed)
  • /lidar/points - Point cloud from LIDAR sensor
  • /radar/markers - RADAR detections as markers
  • /ego_pose - Ego vehicle position and orientation
  • /vehicles/markers - Surrounding vehicle positions

🎨 Color Scheme

  • ■ Yellow cube = Your ego vehicle
  • ■ Blue cubes = Other vehicles
  • ○ Magenta spheres = RADAR detections
  • ● Cyan points = LIDAR point cloud
